实现一个**持续演进、自我自治（Self-Evolving & Autonomous）**的质检 Agent，核心在于引入**反射机制（Reflection）**与**动态知识固化（Dynamic Knowledge Consolidation）**。当 Agent 发现自己的判断与人工标签不符，或者从网页爬取到全新的诈骗手法时，它能够自己分析原因、提取新特征，并自动更新自己的“反诈规则库”和小样本（Few-shot）字典。

以下是完整的系统设计架构以及基于 `learn-claude-code` 哲学实现的核心自治代码框架。

---

## 1. 持续演进自治系统架构

整个系统形成一个闭环，随着输入数据的增加，Agent 的检测精度和规则库会自发演进：

```
                    ┌──────────────────────────────────────────────┐
                    │                                              │
                    ▼                                              │
 ┌──────────────────────────────────────┐                          │ 4. 自动规则提取
 │ 1. 数据输入 (Data Pipeline)          │                          │    与特征固化
 │ - 上百条人工复合 CSV 数据             │                          │
 │ - 动态网络爬虫 (最新诈骗案例网页)     │                          │
 └──────────────────┬───────────────────┘                          │
                    │                                              │
                    ▼                                              │
 ┌──────────────────────────────────────┐       ┌──────────────────┴──────────────────┐
 │ 2. 核心质检 Agent (Executive Agent)  ├──────►│ 3. 演进与反射 Agent (Reflect Agent)  │
 │ - 调用 RAG 检索本地反诈知识库        │ 错判  │ - 对比 [Agent 结论] 与 [人工标签]     │
 │ - 执行高危话术合规性检测             │ 漏判  │ - 分析网页案例，提炼新型诈骗话术模式 │
 └──────────────────┬───────────────────┘       └─────────────────────────────────────┘
                    │
                    ▼
          [ 结构化质检报告 & 告警 ]

```

## 2. 核心自治代码框架实现

以下框架使用 Python 编写，演示了数据读取、双 Agent 协同（质检 Agent + 反射演进 Agent）以及动态规则库自我更新的核心逻辑。

```python
import os
import json
import pandas as pd
from typing import List, Dict, Any
from pydantic import BaseModel, Field
from openai import OpenAI

# 初始化客户端（支持 Claude/Qwen 等大模型）
client = OpenAI(
    api_key=os.getenv("LLM_API_KEY", "your-api-key"),
    base_url=os.getenv("LLM_BASE_URL", "https://api.openai.com/v1")
)

# 模拟本地动态规则库（实际生产中可持久化为 JSON 文件或数据库）
DYNAMIC_RULES_FILE = "dynamic_fraud_rules.json"

def load_dynamic_rules() -> Dict[str, Any]:
    if os.path.exists(DYNAMIC_RULES_FILE):
        with open(DYNAMIC_RULES_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    return {
        "high_risk_keywords": ["福利群", "官方接待员", "打开微信", "加群", "兼职刷单"],
        "fraud_patterns": [
            "以免费升级、延长服务为诱饵，诱导用户添加社交账号引流。",
            "冒充各大证券、投顾公司客服，诱导加群获取内幕股票信息。"
        ],
        "evolved_examples": []  # 存放演进过程中自动提炼的经典错题本
    }

def save_dynamic_rules(rules: Dict[str, Any]):
    with open(DYNAMIC_RULES_FILE, "w", encoding="utf-8") as f:
        json.dump(rules, f, ensure_ascii=False, indent=2)


# ==========================================
# 模块一：核心质检 Agent (Executive Agent)
# ==========================================

class InspectionResult(BaseModel):
    risk_level: str = Field(description="风险等级: LOW, MEDIUM, HIGH")
    risk_category: str = Field(description="风险分类，如：违规投顾引流、冒充客服、合规等")
    detected_features: List[str] = Field(description="检测到的高危特征或敏感词")
    analysis_thought: str = Field(description="质检专家的链式思考和推理过程")
    is_compliant: bool = Field(description="整体是否合规")

def executive_inspection_agent(content: str, current_rules: Dict[str, Any]) -> InspectionResult:
    """主执行 Agent：根据当前规则库对文本进行行业卡质检"""
    
    # 动态将自演进的规则注入到 System Prompt 中
    rules_context = f"""
    当前反诈核心高危词拦截库: {current_rules['high_risk_keywords']}
    当前已知诈骗话术演进模式: {current_rules['fraud_patterns']}
    经典已知案例参考: {json.dumps(current_rules['evolved_examples'], ensure_ascii=False)}
    """
    
    system_prompt = f"""你是一个精通反电信网络诈骗、熟悉重庆通信行业卡合规治理的【智能质检专家】。
    你需要严密审视以下通话内容。结合我们持续更新的质检规则库进行深度推理。
    
    【当前自治规则库上下文】:
    {rules_context}
    
    请输出结构化的 JSON 结果。"""
    
    response = client.beta.chat.completions.parse(
        model="claude-3-5-sonnet-20241022", # 或 qwen-plus
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": f"请质检以下话术内容：\n{content}"}
        ],
        response_format=InspectionResult,
    )
    return response.choices[0].message.parsed


# ==========================================
# 模块二：演进与反射 Agent (Reflect Agent)
# ==========================================

class EvolutionProposal(BaseModel):
    need_evolution: bool = Field(description="是否需要对现有规则库进行演进/修正")
    new_keywords: List[str] = Field(description="从该新案例中提炼出的、以前未覆盖的新型高危词汇/话术特征")
    pattern_update: str = Field(description="对新型诈骗手法的总结概括（若有），将加入知识库")
    reflection_notes: str = Field(description="反射思考：为什么之前的规则会漏判/误判，如何改进")

def reflect_and_evolve_agent(content: str, agent_res: InspectionResult, target_label: str) -> EvolutionProposal:
    """自治核心：对比人工标签或网页最新案例，反思并输出规则升级建议"""
    
    system_prompt = """你是一个高阶【反诈策略进化专家】。你的职责是观察质检 Agent 的表现以及最新的外部案例。
    当质检 Agent 的判断与预期标签（人工标注或最新网页毒瘤案例）不符时，或者发现了全新的诈骗话术，你需要执行【反射与自我进化】。
    找出质检 Agent 知识的盲区，提炼出新的规则特征，以防止未来再次漏判。"""
    
    user_content = f"""
    【输入案例内容】: {content}
    【主质检Agent的判定】: {agent_res.model_dump_json(ensure_ascii=False)}
    【预期正确标签/业务线索】: {target_label}
    
    请对比并反思，如果主 Agent 判断存在盲区或这是个全新的诈骗变体，请提炼并输出升级方案。
    """
    
    response = client.beta.chat.completions.parse(
        model="claude-3-5-sonnet-20241022",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_content}
        ],
        response_format=EvolutionProposal,
    )
    return response.choices[0].message.parsed


# ==========================================
# 模块三：自治循环调度器 (Scheduler Pipeline)
# ==========================================

def run_autonomous_pipeline(csv_path: str, web_scraped_data: List[Dict[str, str]]):
    """自动化演进主循环"""
    # 1. 加载当前演进阶段的规则库
    current_rules = load_dynamic_rules()
    
    # 2. 处理人工复合数据 (带 Comment 标签)
    df = pd.read_csv(csv_path)
    print(f"开始执行自治演进系统。当前规则库已知高危词数量: {len(current_rules['high_risk_keywords'])}")
    
    for _, row in df.iterrows():
        content = row['content']
        human_comment = row['comment']
        
        # 主 Agent 进行质检
        inspection_res = executive_inspection_agent(content, current_rules)
        
        # 自动化对齐检测：如果主 Agent 认为合规，但人工打标为“引导投资”（存在分歧）
        is_conflict = (inspection_res.is_compliant == True) and (pd.notna(human_comment))
        
        if is_conflict:
            print(f"⚠️ 发现判定分歧 (ID: {row['data_id']})。正在激活 Reflect Agent 进行自我反思...")
            
            # 激活反射 Agent 寻找知识盲区
            evolution_proposal = reflect_and_evolve_agent(content, inspection_res, f"人工标记为: {human_comment}")
            
            if evolution_proposal.need_evolution:
                print(f"💡 反射成功！更新规则提示: {evolution_proposal.reflection_notes}")
                # 动态合并新提炼的知识，实现自治
                for kw in evolution_proposal.new_keywords:
                    if kw not in current_rules['high_risk_keywords']:
                        current_rules['high_risk_keywords'].append(kw)
                
                if evolution_proposal.pattern_update and evolution_proposal.pattern_update not in current_rules['fraud_patterns']:
                    current_rules['fraud_patterns'].append(evolution_proposal.pattern_update)
                
                # 把该错题作为 Few-Shot 样本固化下来
                if len(current_rules['evolved_examples']) < 10:  # 限制核心错题本大小
                    current_rules['evolved_examples'].append({
                        "text": content,
                        "analysis": evolution_proposal.pattern_update
                    })
                
                # 持久化规则庫
                save_dynamic_rules(current_rules)
                
    # 3. 处理网页爬取的最新案例数据（假设无人工标签，纯粹用于特征吸收）
    print("\n--- 开始吸收网页爬取的最新诈骗案例特征 ---")
    for web_case in web_scraped_data:
        # 直接让主 Agent 测一下，看能不能识别
        inspection_res = executive_inspection_agent(web_case['text'], current_rules)
        
        # 如果新爬取的案例里包含明显的诈骗倾向而主 Agent 漏报，或者需要吸收其中更前沿的话术
        evolution_proposal = reflect_and_evolve_agent(
            web_case['text'], 
            inspection_res, 
            "这是最新网页爬取的已被确认的网络诈骗通报案例"
        )
        
        if evolution_proposal.need_evolution:
            print(f"🔥 捕获到新型网页诈骗话术特征，正在自动融入知识库...")
            for kw in evolution_proposal.new_keywords:
                if kw not in current_rules['high_risk_keywords']:
                    current_rules['high_risk_keywords'].append(kw)
            save_dynamic_rules(current_rules)

    print(f"\n系统演进完毕。当前规则库已知高危词数量已自动增长至: {len(current_rules['high_risk_keywords'])}")

# ==========================================
# 模拟运行
# ==========================================
if __name__ == "__main__":
    # 模拟从网络爬取到的最新、更隐蔽的重庆本地话术案例

    ]
```

## 3. 该架构如何确保“持续演进与自治”？

1. **零人工干预的规则沉淀：** 传统的系统需要安全专家人工去更新正则表达式或关键词列表。这个架构里，`reflect_and_evolve_agent` 扮演了**安全专家**的角色，自动将新增的行业卡违规词汇和话术套路写入 `dynamic_fraud_rules.json`。
2. **动态小样本注入（Few-Shot Seed）：** 随着运行，`evolved_examples` 会自动收集最容易让主 Agent 产生混淆的边缘案例（Edge Cases），并在下一次运行时作为主 Agent 的输入。这使得主 Agent 越用越聪明。
3. **完美契合行业卡高频更迭的特性：** 诈骗团伙今天用“企辽通”，明天可能用新话术。网络爬虫模块只要抓取到最新的警方通报通字，自治 Agent 就会在几秒钟内将其拆解、吸收并覆盖到线上质检流程中，完成自治闭环。
