# 行业卡对客反诈最新复核规范（决策表）

> 来源：业务附件《行业卡对客反诈最新复核规范》（CSV/表格口径）。  
> 本文件为可检索的规范摘要，与 `rules.json` 同步；细节与典型话术仍以 `spec.md`（V1.1）为准。  
> 原则：**就高不就低**；涉诈场景风险等级一律为**高风险**。

## 标注目标

基于通话录音转写的 ASR 文本，识别该通话是否高风险涉诈。

## 备注

1. 遇到违规场景，优先根据通话语境判断是否涉诈；确认为涉诈时，登记时需标注为诈骗，与违规场景进行区分。
2. 对违规场景的判断，采用**就高不就低**的原则进行分类。如通话中引导微信群（引流第三方平台），明确为炒股群，因【证券投资类】风险级别更高，可判断为【证券投资类】。

## 违规场景

### 1. 引流第三方平台 → 违规

**非个人微信（高风险）**  
加 QQ、YY、微信群、企业群、qq 群、下载 APP、浏览器打开、扫描二维码、关注公众号/服务号。

**个人微信**

1. 工作人员主动添加用户微信，不区分场景，判为合规；
2. 由第三方添加用户微信：贷款场景为低风险，其他场景合规；低风险场景须标注清楚；
3. 引导用户主动添加微信，不区分场景，均为高风险（包括让用户添加外呼人员本机号码微信，以及第三方微信）。若该场景同时符合【引导用户添加私人微信】涉诈套路（平台客服核资后引导加下款/放款经理等），按涉诈类标注。

### 2. 贷款相关 → 违规

1. 合规平台（合规）：银行、消金、融 360 等  
2. 助贷包装（合规）：个人贷款包装为经营性贷款，无其他违规话术时  
3. 过分承诺（低风险）：包过、包批、100% 下款、内部渠道、保证金、解冻金、零利息  
4. 提前收取费用（低风险）：定金、手续费等  
5. 网贷/小贷平台（低风险）：度小满、安逸花、拍拍贷、分期乐、理想花、花呗等；确认是对应平台才标注平台名  
6. 不看征信（低风险）  
7. 涉及违规收取费用（中风险）  
8. 平台客服诱导签协议后平台下款再收取高额费用（中风险）；可参考第 5 条  
9. 贷款债务优化（高风险）：帮处理高利息平台债务、以法律咨询名义诱导做贷款替换（借低息还高息）。  
   **例外**：某些场景下只谈债务优化为目的且不收费，可判为合规  
10. 砍头息贷款（高风险）：如贷款 1w 到手 8k  
11. 引导用户平台操作下款（高风险）：以利息下调活动/内部会员为由，引导用户在度小满/公众号/APP 等操作下款，偏套路贷高风险。通话中出现套路平台名（如度小满借钱等）时尤需关注；可与【贷款降息诱导套现诈骗】联动  
12. 征信/芝麻分截图标注标准  
    - 仅询问征信、未明确落入其他违规场景 → 合规  
    - 要求提供支付宝/微信芝麻分截图并查询芝麻分，且话术配合度小满等平台/疑似套路 → 高风险涉诈；仅手机租赁套路贷场景中要求芝麻分截图，归【手机租赁套路贷诈骗】  
    - 若同时涉及引导对接/添加私人微信 → 按【引导用户添加私人微信】高风险涉诈标注

### 3. 法律服务 → 违规

1. 法律机构维权名义帮用户要回欠款、一般涉及收费 → 违规（低风险）。例：补缴手续费/保证金至个人账户、验证资金流水要求多次转账、充值解冻账户、维权要求支付调档费等  
2. 自称维权成功后收取一定费用 → 高风险

### 4. 企业营销与招商服务 → 违规

1. 品牌招商加盟（合规）：棋牌/零食店加盟、邀请阿里国际站开店  
2. 人工电话获客 / 人工智能客服（合规）：无年付/半年付 GEO 收费等违规要素时  
3. AI/小红书推广获客（低风险）：收费提供 GEO/排名/引流  
4. 会展营销（低风险）：涉及提前收费为低风险，否则合规  
5. 企业培训营销提前收费（低风险）：培训班/学校课程培训考证/年报辅导等，涉及提前收费  
6. 企业代开虚假发票（中风险）：代开发票中介，对公户/多人发票成本收取费用，涉及逃税漏税风险  
7. 企业注册/注销群/年报代办（中风险）：为企业提供注册/注销/年报服务，但个人账户收取费用

### 5. 商品推销 → 违规

1. 经营类业务推销（合规）：校园前经营、携号转网、培训等正常推销  
2. 赠送 POS 机（低风险）：涉及几百上千刷够流水后才能提现为低风险；只收几十块运费为合规  
3. 保健品推销（中风险）：免费领 → 加微信后洗脑 → 高价保健品 → 货到付款/到付运费/会员费/套餐费 → 反复骚扰、连环下单掏空老人积蓄

### 6. 商业地产 → 违规

1. 商铺销售不提前收取推广费（合规）：中介转介要求签合同支付推广费等，确认为合规业务  
2. 法拍房处理（低风险）：用户欠债房子被拍卖，代处理法拍房  
3. 代客运营租房装修收费（中风险）：长期合作代运营租房，需先按指定风格委托装修

### 7. 违规催收 → 违规

1. 通讯录催收（向欠款人亲友、同事催收）→ 违规（低风险）  
2. 暴力催收（威胁联系亲友、上门催收、报身份证/住址威胁等）→ 违规（低风险）  
3. 冒充公检法催收（高风险）：冒充法院人员、公司网站人员、纪检等公检法人员，实际目的为催收  
4. 对本人催收 → 合规

### 8. 其他 → 违规

询问或确认个人敏感信息（高风险）：身份证号、家庭住址等

## 涉诈类型（均为高风险）

### 1. 机票退、改签诈骗

冒充某航空公司官方客服来电，以航班设备故障无法起飞为由，引导改签/退票，再引导领取赔付、屏幕共享或软件下载转账。

### 2. 手机租赁套路贷诈骗

以租赁手机/商品下单形式做资金周转，均为诈骗；通话类型可能为租赁手机贷款或租赁手机贷款催收；亦含设备租赁平台招募区域服务商等变体。

### 3. 证券投资类

凡是加炒股群、证券投资、理财等，如黄金/基金/股票/外汇/彩票等，均为诈骗。

### 4. 网贷平台退息退费

1. 以法律维权协助办理网贷平台退息退费为由，引导加法务老师微信，退费后付款；实际加微信后可能骗取个人信息及要求转账付费  
2. 自称平台退费专员/维权专员，承诺已还清会员费等后收费

### 5. 个体工商户年报补录收费

自称线上税务/服务中心点，以个体工商户未按时年报申报为由，引导企业微信/小程序缴纳信息补录费用。

### 6. 贷款相关-AB贷（涉诈）

要求企业贷资金进入指定账户到账后划转，或指定联系人、合法背调等，构成 AB 贷风险：

1. 专款专用：装修贷/经营贷等，主体要求企业账户收款/个人账户转到企业账户收款，取指定收款人  
2. 对贷后管理/账户要求企业侧合法背调，提供指定联系人的背调  
3. 受托支付、委托支付等确认方式由企业侧控制资金流向  
4. 企业侧双签等

### 7. 引导用户添加私人微信（涉诈）

平台客服/人工审核主体核对用户信息后，引导用户主动添加下款经理/放款经理/客服主管/加急审核等私人微信/企业微信，判为涉诈：

1. 平台客服/人工审核核资后，引导用户主动添加下款经理/放款经理/客服主管/加急审核数据的微信/企业微信  
2. 目前征信套路线上多见以度小满等平台为幌子操作下款  
3. 有些通话虽未明确说加微信，但提及对接经理等，视为同套路  
4. 仅仅引导用户关注公众号后通过公众号对接人工客服/放款经理，视为不同套路（仍按引流/违规相关规则判断，不直接升本条涉诈）

### 8. 路费诈骗

提及有薪招聘某公司，有集中仓库地址和固定路线，入职需收取费用，判为路费诈骗：

1. 招聘个人/公司有集中仓库、本地仓库等模式，提供驻站和固定路线，需垫付押金/保证金；平台派单到公司/客户  
2. 入职收取司机约 800 元平台注册费/服务费，承诺第一单就有约 500 等
